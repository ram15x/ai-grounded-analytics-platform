# Phase 1c-1: assumptions about provider behaviour (mostly UNVERIFIED)

The model router, adapters and cassettes were built against mocked HTTP only; since 2026-11-20 three real runs on Groq exist (see Status column). Every item
below is an assumption the code makes. Each must be checked against real calls (by hand, with keys
in the environment) before any number from a live run is trusted. Tests use mocked HTTP only, so a
passing test proves the code does what these assumptions say, not that the assumptions are true.

**Status column.** Every row is STILL UNKNOWN until real output from `grounded live models` or `grounded live probe`
has been pasted back and read. A row is changed to CONFIRMED or REFUTED only from that output, with the
date and the line that shows it, never from memory. "Settled by" names the output that can decide it.
Real output so far, all 2026-11-20: one `grounded live models --provider groq` run and two `grounded live probe --provider groq --model openai/gpt-oss-20b --quota-check` runs (run 1 with the v0 compose prompts, run 2 with compose.v1/repair.v1 and the minute bucket). Rows they settle are marked below, for Groq and that model only; everything else is STILL UNKNOWN. These are single runs (n as stated in each row), not repeated.
