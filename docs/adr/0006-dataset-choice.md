# ADR-0006: Dataset choice

Status: PROPOSED, needs owner decision

Proposal: Primary sales and customer data from UCI Online Retail (CC BY 4.0). Optional second dataset Olist (CC BY-NC-SA 4.0) only if the owner accepts non-commercial and share-alike terms. Support text from Bitext after its CDLA-Sharing terms are read. Documents: synthetic corpus built from a ground-truth fact table. Benchmark: BIRD dev set (CC BY-SA 4.0).

Why open: licence trade-offs, and the dataset determines the semantic layer and gold set. Details and sources in docs/RESEARCH.md.
